# Astro content workflow

For content-heavy private projects, model content explicitly with Astro Content Collections and typed schemas where it adds safety. Keep editorial content separate from presentation logic. Prefer Markdown/MDX only when authoring needs justify MDX components; plain Markdown remains the simpler default.
