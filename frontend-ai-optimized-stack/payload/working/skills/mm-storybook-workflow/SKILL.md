# Storybook working workflow

Use Storybook as the executable component catalog for working projects that provide it. Read existing stories and component documentation before inventing new examples. Add or update stories alongside meaningful component behavior changes. Use the project-local Storybook MCP only when that repo has the addon configured and its dev server is running.
